# 안디잇굿 (Anditgood) 🎨

> **예술을 일상적으로 누리도록 돕는 챌린지 기반 앱**

거창하지 않아도 괜찮아요. 작은 챌린지로 하루에 한 조각씩, 예술을 일상으로 들여오는 습관을 만드는 모바일 우선 웹 프로토타입입니다.

## ✨ 핵심 기능

### 1. 온보딩 · 예술 타입 진단
무신사 옷 타입 테스트처럼, 6문항으로 나의 예술 성향을 4가지 페르소나로 진단합니다.

| 타입 | 코드 | 한 줄 |
| --- | --- | --- |
| 🌙 몽상가 | AF | 느끼는 대로 스며드는 사람 (감상 × 감성) |
| 🗂️ 큐레이터 | AT | 고르고 엮어 나누는 사람 (감상 × 탐구) |
| 🎨 창작자 | EF | 직접 만들며 표현하는 사람 (표현 × 감성) |
| 🧭 탐험가 | ET | 경험하며 넓혀가는 사람 (표현 × 탐구) |

두 축(감상↔표현 / 감성↔탐구)의 조합으로 타입을 결정하고, 타입별 추천 시작 목표를 제안합니다.

### 2. 4개 핵심 탭

- **미션 · 챌린지** — 참여 중인 챌린지의 오늘 미션을 바로 수행/인증. 캐시(투자금)를 예치하고 완주하면 보상 캐시 + 뱃지를 획득합니다. 인증 시 남긴 사유는 아카이브에 저장됩니다.
- **예술 콘텐츠** — 인스타그램 형식의 피드. 카테고리(작품 · 상식 · 전시·정보 · 뉴스 · 저자극) 필터, 좋아요/저장, 선별 광고 표시, 저장함 보기, 업로드 진입점을 제공합니다.
- **커뮤니티** — 오픈 그룹 / 지정 그룹으로 나눠 활동·교류. 내 그룹 바로가기와 그룹 둘러보기·가입.
- **마이페이지** — 개인 프로필(이름 · 한 문장 소개), 타입 & 목표, 성장 지표(연속·완주·뱃지), 캐시(투자금), 활동/사유 아카이브, 뱃지 컬렉션.

## 🛠 기술 스택

- **React 18 + TypeScript + Vite**
- 상태 관리: React Context + `localStorage` 영속화 (백엔드 없이 동작)
- 디자인: 따뜻한 갤러리 톤 디자인 시스템 (CSS 변수 기반), 모바일 우선 · 데스크톱 폰 프레임

> 현재는 목업 데이터 기반 프론트엔드 프로토타입입니다. 실제 서비스로 확장 시 인증/서버/결제(캐시)/실시간 커뮤니티를 붙일 수 있도록 데이터 모델을 분리해 두었습니다.

## 🚀 실행

```bash
npm install
npm run dev      # 개발 서버 (http://localhost:5173)
npm run build    # 타입체크 + 프로덕션 빌드
npm run preview  # 빌드 결과 미리보기
```

## 📁 구조

```
src/
├─ App.tsx                # 앱 셸 · 하단 탭 네비게이션
├─ store.tsx              # 전역 상태 + localStorage
├─ index.css             # 디자인 시스템
├─ data/
│  ├─ artTypes.ts        # 예술 타입 · 진단 퀴즈 · 채점 로직
│  └─ content.ts         # 챌린지 · 피드 · 커뮤니티 · 뱃지 목업
├─ components/
│  ├─ icons.tsx          # SVG 아이콘
│  └─ ui.tsx             # 토스트 · 바텀시트 · 프로그레스바
└─ screens/
   ├─ Onboarding.tsx     # 인트로 → 퀴즈 → 결과 → 프로필
   ├─ Challenge.tsx      # 미션 · 챌린지
   ├─ ArtContent.tsx     # 예술 콘텐츠 피드
   ├─ Community.tsx      # 커뮤니티
   └─ MyPage.tsx         # 마이페이지
```
